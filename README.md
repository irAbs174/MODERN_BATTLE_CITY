# MODERN_BATTLE_CITY

A polished, modern reimagining of the NES classic **Battle City** — top-down tank
combat, destructible terrain, a protected HQ, and escalating enemy waves — rebuilt
from scratch with meta-progression, five game modes, and **zero external assets**.
Every sprite is drawn procedurally to canvas and every sound is synthesised in the
browser with the Web Audio API.

Built with **Vite + TypeScript + Canvas 2D**. No game engine, no image files, no
audio files, no copyrighted material.

---

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173
```
